## Where the project got to

The panorama is built by `tools/stitch_lab.py` running as Python under Pyodide
**inside the app**, over the same capture-debug ZIP a desktop rebuild reads. In
app and on desktop are the same program over the same bytes, so a disagreement
between them is a runtime bug and never a pipeline difference.

Best measured result — the 2026-08-21 capture, 103 frames, SIFT 3000:

| | |
|---|---|
| frames placed | **103 / 103**, one component, none excluded |
| overlap disagreement | 15.5 mean, 47.8 p95 |
| residual (post-prune) | 0.086° median |
| solve time | ~100 s desktop, ~2 min in browser |

## Design decisions that are load-bearing

**One lap, not two.** A second lap is walked from a different standing position,
and against anything close that is real parallax a rotation-only model cannot
represent. `RULES.singleLapObservations` lets a bin verify inside one lap on a
*harder* standard (8 looks, 70% of the spread allowance, confidence 0.55).

**Overlap disagreement is the headline metric, not residual.** The residual is
computed after `prune_outliers` deletes the matches that disagree, so it improves
when evidence is discarded — on the 08-18 capture it called the ghosted two-lap
build *better* than the clean one-lap build while the picture was 36% worse.

**The dot is the instruction, never an angle.** There is no protractor in a
viewfinder. The band step is 0.40 of the vertical field, and the binding
constraint is not the matcher but that the dot must stay on screen — at half the
vertical field it lands off the top edge.

**Serpentine, enforced.** The dot may not move sideways while the column under it
is unfinished, and reverses vertical direction when one completes. It gives up
after `columnPatienceSec` (12 s) without progress, because a column that cannot
be reached must not pin the dot.

## Bugs found in the 08-21 pre-field sweep

All fixed and covered by tests. Listed because each one hid behind something that
looked fine.

1. **A tall sector could never satisfy its own lift rule.** The ask was
   `top − vfov×0.35`; satisfaction needed `elevation ≥ top − vfov×0.325`. The
   dot asked for an elevation ~1° lower than its own rule demanded, forever.
   `isComplete = isCovered && !needsLift`, so that bearing never completed and
   the frontier never passed it. Both now derive from `aimForTop()`.
2. **The requirement froze once a frame stopped clipping.** It was only
   recomputed inside the clipped branch, so the ask stayed pinned to a lower
   bound taken from a frame that was too low. A measured top now revises it.
3. **Sky frames could not fill a column band.** The plan was credited with
   `observationQuality`, which is zero for `allSky`/`clippedTop` — and the top
   band of a tall column is *by construction* aimed over the obstruction. Tall
   columns could never complete, so the serpentine hold would abandon every one.
   Now credited with `structuralQuality`.
4. **`observe()` hung forever on a large heading.** `for (slot = first; slot <= last; slot++)`
   at 5e299 cannot advance — 1 is below the ULP. Per-frame path; the device
   freezes mid-survey with no error. Heading is wrapped first.
5. **`demote()` spun 500 million times** on a wide sector (6 s freeze). Bounded.
6. **`keyframeStepDeg(NaN)` returned NaN**, making `keyframeSpacingReached` false
   forever — the app would silently stop photographing while logging
   `spacing-not-reached`. Intrinsics are computed, so this is reachable.
7. **Dome view used `mediump`** (~3 px sampling error on mobile; desktop hides
   it), never redrew on rotation, and did not survive WebGL context loss.
8. **Export wrote `column-plan.json` and `overlap-audit.json` as `null`** — two
   payload builders had drifted. Now one.
9. **Four test suites had been red for so long nobody read them**, which is how
   1–3 hid. All 31 suites and 7 sims are green as of this commit.

## Known-imperfect, deliberately

- **`k1 = −0.10` is imposed, not solved.** It is degenerate with focal length —
  imposing it moves the solved focal 1.6%. Three of four metrics improve and
  mean disagreement worsens 10%; the deciding evidence is that clapboard is
  straight under a rectilinear view. *Next step: solve k1 in `bundle_adjust`.*
- **Module caching is still per-file.** `main.js?v=X` busts one file; its imports
  carry no query. The mismatch is now *detected* and shown in an un-clobberable
  banner, but the real fix is a build step that fingerprints every module.
- **`maxKeyframeYawRate()` ignores its argument.** The per-mode ceilings (tripod
  20, probe 3) were removed at some point; a probe frame is now admitted at the
  same 35°/s as an ordinary sweep. Nothing is broken — the ramps still discount
  fast frames — but the hard gate no longer distinguishes them.
- **The near umbrella cannot be stitched.** It is an arm's length away; no
  rotation places it. It correctly earns no coverage credit and the seam-cutter
  gives it to one photograph. This is physics, not a defect.

## Where things live

| | |
|---|---|
| `js/coverage.js` | the ring: what has been observed, and how good each look was |

| `js/coverage-table.js` | per-bearing and per-photograph evidence tables |
| `tools/stitch_lab.py` | the solver — features, matching, bundle adjustment, seam compositing |
